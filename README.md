# ZQK Swarm Starter Kit

Official starter swarm package for [ZQK OS](https://zqk.dev).

## Quickstart

Run directly using the ZQK CLI:

```sh
zqk run https://github.com/zqk-os/swarm-starter-kit
```

Or clone and run locally:

```sh
git clone https://github.com/zqk-os/swarm-starter-kit
zqk run ./swarm-starter-kit/
```

## Structure

- `swarm.yaml`: Declarative swarm manifest defining participating agent roles, skills, and task dependencies.

## Documentation

For full swarm documentation and guide, see [docs.zqk.dev](https://docs.zqk.dev).
